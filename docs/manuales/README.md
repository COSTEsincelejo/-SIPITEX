## Cómo entrar al sistema

1. Abrir la URL de SIPITEX (por ejemplo `http://localhost:5240`).
2. Iniciar sesión con el correo y la contraseña de su rol.
3. Usar el **menú lateral** y, para su cuenta, **Mi perfil** (menú o clic en el nombre arriba a la derecha).

Si olvida la contraseña: en la pantalla de login use **¿Olvidaste tu contraseña?**.
