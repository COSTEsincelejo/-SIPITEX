# Proyecto formativo SENA — SIPITEX (puntos 1–9)

Documento alineado con la estructura del ejemplo de proyecto formativo SENA, adaptado a **SIPITEX**.

## Archivos

| Archivo | Descripción |
|---------|-------------|
| `PROYECTO_FORMATIVO_SIPITEX_PUNTOS_1_9.docx` | Documento Word listo para entregar / editar |
| `PROYECTO_FORMATIVO_SIPITEX_PUNTOS_1_9.md` | Fuente en Markdown |
| `generate_docx.py` | Script para regenerar el DOCX con diagramas |

## Contenido (puntos 1–9)

1. Levantamiento de información  
2. Informe de requerimientos  
3. Hardware del cliente  
4. Diagrama de Gantt  
5. Casos de uso  
6. Diagrama de flujo  
7. Diagrama de clases  
8. Diagrama de distribución  
9. Modelo entidad relación  

Los diagramas PNG viven en [`../diagramas/`](../diagramas/).

## Regenerar el DOCX

```bash
pip install python-docx
python3 docs/proyecto-formativo/generate_docx.py
```
